# The external constants this development cites that reach `Classical.choice`.
# `scripts/classical.lean` prints this set and `gate.sh` fails on a name that is not here.
# A name that leaves the output is a fall and passes. To re-baseline, copy the output over
# this file's name rows.
#
# Four groups, and the reason no rule filters any of them: a filter is a second policy, and
# a policy rots where a name does not.
#
#   Finset and Fintype   membership in a `Finset` resolves through `Finset.instSetLike`,
#                        whose injectivity field is proved classically.
#   String and Nat       core Lean's own proofs reach `Classical.propDecidable`. The shortest
#                        path from `String.ofList_injective` runs through
#                        `List.utf8Decode?_utf8Encode` and the UTF-8 decoding lemmas. This
#                        route is independent of the Finset one: cut `Finset.instSetLike` and
#                        choice is still reachable from here.
#   Lean and Batteries   the guard's own elaborators in `Axioms.lean`, not proof appeals.
#                        `#lint_calculus` and `#assert_axioms_all` are `CommandElabM`, and the
#                        monad plumbing under them carries choice. The simp sets that
#                        `Dynamo/Lang/Term.lean` registers are `initialize` declarations,
#                        and the registration code carries choice the same way.
