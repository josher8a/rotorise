# The rows of the type bridge where the type checker disagrees with the run time.
# `scripts/type_bridge.py` prints this set and fails on an id that is not here.
# An id that leaves the output is a fall and passes. To re-baseline, run
# `python3 scripts/type_bridge.py --accept`, which writes the output over this file's id rows.
#
# An id is the group, the verdict of the run time, a hash of the Lean print of the root, and
# the text of the check. An `accept` id is a place where the type refuses what the run time
# accepts. A `refuse` id is a place where the type accepts what the run time refuses.
#
#   call         the clause of an `extract` or an `exclude` on a union of objects.
#   extract      one member of the union under a clause that the run time accepts: the run
#   exclude      time keeps the member (`accept`) or drops it (`refuse`).
#   path         one path under `at`: `accept` where the run time resolves one codec.
#   decoded      one sample value of the codec at a path, assigned to `Decoded` of that codec.
#                A `refuse` row is a foreign sample: a value of another kind, one for each family of
#                codec, which the run time refuses and the type must refuse.
#   encoded      one key that the run time writes at a path: `encode` at the path admits it.
#   meet         the call of `meet` on two codecs: `accept` where the run time gives a codec,
#                `refuse` where the run time gives none.
#   meetvalue    one sample value of the codec that `meet` gives, assigned to `Decoded` of it.
#   declaration  one constant of the generated codecs file: the run time built each one.
#
# The groups of the entry pool (`.entry.types/`, from `lean.entry.spec.ts`) put the methods of an entry to
# the type checker. An id has the same form. The hash is the hash of the draw: an entity, a key spec and
# its options.
#
#   construct    one call of `tableEntry`. `accept` where the run time builds the entry, and `toEntry`
#                builds each plain item. `refuse` where the construction throws, or where `toEntry` throws
#                for a plain item. A `refuse` row has no row of a method.
#   toEntry      one call of `toEntry` on an item that is a variable of its declared type. `accept` where
#   fromEntry    the run time gives the value, as `key`, `fromEntry` (on the row of `toEntry`) and
#   key          `keyUpdates` do, each with the value of the run time assigned to the type of the result
#   keyUpdates   (a `result` row), and one foreign value under `@ts-expect-error` (a `foreign` row). A
#   infer        `refuse` call row is a place where the run time throws and the type accepts.
#                `infer` assigns the row of `toEntry` to the type of the entity.
#   typing       one item of a draw assigned to the entity type. An error is a defect of the generator and
#                a hard failure of the script, so no id of this group is in the list.
