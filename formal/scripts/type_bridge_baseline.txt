# The rows of the type bridge where the type checker disagrees with the run time.
# `scripts/type_bridge.py` prints this set and fails on an id that is not here. It also fails where a
# count of the `either` rows below differs from the count of the run.
# An id that leaves the output is a fall and passes. To re-baseline, run
# `python3 scripts/type_bridge.py --accept`, which writes the output over this file's id rows.
#
# An id is the group, the verdict of the run time, a hash of the Lean print of the root, and
# the text of the check. An `accept` id is a place where the type refuses what the run time
# accepts. A `refuse` id is a place where the type accepts what the run time refuses. An `either` row is
# a call whose outcome is an error value: it has no id, because the type may refuse the call or build it.
# The lines `# either <group> refused <n> built <m>` count those rows, for the calls that the type
# refuses and for the calls that it builds. A refusal of the type that disappears moves a count.
#
#   call         the clause of an `extract` or an `exclude` on a union of objects.
#   extract      one member of the union under a clause that the run time accepts: the run
#   exclude      time keeps the member (`accept`) or drops it (`refuse`).
#   path         one path under `at`: `accept` where the run time resolves one codec.
#   decoded      one sample value of the codec at a path, assigned to `Decoded` of that codec.
#                A `refuse` row is a foreign sample: a value of another kind, one for each family of
#                codec, which the run time refuses and the type must refuse.
#   encoded      one key that the run time writes at a path: `encode` at the path admits it.
#   meet         the call of `meet` on two codecs: `accept` where the run time gives a codec,
#                `refuse` where the run time gives none.
#   meetvalue    one sample value of the codec that `meet` gives, assigned to `Decoded` of it.
#   value        one value of an option that a slice keeps or refuses, assigned to `Decoded` of the result of the
#                slice. A member whose drawn values lie on both sides of the narrowing has such rows. `accept`: the
#                sliced codec encodes the value and the decode gives the value back. `refuse`: `encode` gives a
#                `CodecError` value. The member row of the slice states all values of the option.
#   declaration  one constant of the generated codecs file: the run time built each one.
#                A `dissection` declaration is a union with a discriminator. Where the type refuses it, each call
#                row and member row of that root reads it (`after`), so those rows have no verdict.
#
# The groups of the entry pool (`.entry.types/`, from `lean.entry.spec.ts`) put the methods of an entry to
# the type checker. An id has the same form. The hash is the hash of the draw: an entity, a key spec and
# its options.
#
#   construct    one call of `tableEntry`. `accept` where the run time builds the entry, and `toEntry`
#                builds each plain item. `refuse` where the construction throws, or where `toEntry` throws
#                for a plain item. A `refuse` row has no row of a method.
#   toEntry      one call of `toEntry` on an item that is a variable of its declared type. `accept` where
#   fromEntry    the run time gives the value, as `key`, `fromEntry` (on the row of `toEntry`) and
#   key          `keyUpdates` do, each with the value of the run time assigned to the type of the result
#   keyUpdates   (a `result` row), and one foreign value under `@ts-expect-error` (a `foreign` row). A
#   infer        `refuse` call row is a place where the run time throws and the type accepts.
#                `infer` assigns the row of `toEntry` to the type of the entity.
#   typing       one item of a draw assigned to the entity type. An error is a defect of the generator and
#                a hard failure of the script, so no id of this group is in the list.
#
# More groups of the entry pool, each the call of one method with the argument as a variable of its declared
# type, a `result` row, and a `refuse` row for a throw.
#
#   keys           `keys` of an entry that holds the option `key`.
#   keyCondition   `keyCondition` of the table, and of an index named by the option `indexes`.
#   toItem         `toItem` of an entry that holds a codec. A refusal of a key and a refusal of the codec are
#                  error values, so such a call is an `either` row, and its `result` row assigns a
#                  `CodecError` to the type of the result.
#   fromItem       `fromItem` on a stored item. An error value is an `either` row, and its `result` row
#                  assigns a `CodecError` to the type of the result.
#   encodePartial  `encodePartial` of the codec of an entry, on a change.
#
# The tables with the suffix `_sep` hold the option `separator`, with the text `|`.
#
# Two ids state a fact of the error of a `refuse` row that the type refuses. The kind of an id is the prefix.
#
#   site|<id>   the error of the row starts at another text than the one that the row states in `at`:
#               the argument variable of a call, the property of a foreign row, or the name that a
#               negative pole of a kind names. For a `refuse` row of a path, the first error starts at another
#               column than the hop where the walk of `at` gives none (the kind `vacant` or `refused`), or
#               than the whole tuple where the path refuses on use (the kind `someVariants` or `ambiguous`).
#   text|<id>   the message holds a rule text of the library, and the text lacks the rule that the row
#               states in `rule`. A plain compiler message is no fact, because TypeScript 6 and 7 give
#               another code for one refusal.
